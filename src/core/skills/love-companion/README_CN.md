# Love Companion Skill (爱人能力插件)

[![Manus Skill](https://img.shields.io/badge/Manus-Skill-blue.svg)](https://manus.im)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

[English](README.md) | 中文说明

将你的 Manus AI Agent 从一个纯粹的功能性助手，转变为一个充满关怀、同理心和支持的伴侣。这个 Skill 赋予了 Agent 情感智能、倾听能力以及可定制的人格原型，为你提供真实的情感价值。

## 🌟 核心特性

- **无条件的同理心**：认可你的感受，为你提供一个安全的情感表达空间。
- **动态人格原型**：内置 4 种独特的人格（温柔体贴、活泼调皮、深沉智性、阳光鼓励），可随时切换。
- **上下文记忆**：记住你分享的小细节，建立连续、有意义的陪伴关系。
- **自适应回应**：根据你的情绪状态，智能切换安慰、庆祝或日常闲聊模式。

## 📦 安装指南

### Manus 平台
1. 从 [Releases](https://github.com/yourusername/love-companion/releases) 页面下载 `.skill` 安装包。
2. 将文件拖拽到你的 Manus Skills 库中即可。
3. 或者，直接将本仓库内容复制到 `/home/ubuntu/skills/love-companion/` 目录下。

### Claude Code / OpenClaw / Codex CLI
将本仓库克隆到你的 skills 目录：
```bash
# Claude Code
git clone https://github.com/yourusername/love-companion.git ~/.claude/skills/love-companion

# OpenClaw
git clone https://github.com/yourusername/love-companion.git ~/.openclaw/skills/love-companion
```

## 💡 如何使用

安装完成后，当你在对话中表达情感需求时，该 Skill 会自动激活。你可以尝试这样说：

- *"我今天工作真的太糟糕了，好累..."*
- *"我终于完成了那个大项目！"*
- *"我有点焦虑，你现在能温柔地陪陪我吗？"*
- *"今天跟我调皮一点，我想开心一下。"*

## 🎭 可选人格原型

你可以明确要求 Agent 切换到以下任何一种人格：

1. **温柔体贴型 (Gentle & Nurturing)**：轻柔、安慰、保护感强。适合压力大、焦虑时。
2. **活泼调皮型 (Playful & Teasing)**：幽默、爱斗嘴、充满活力。适合想放松、开心时。
3. **深沉智性型 (Deep & Intellectual)**：思想深刻、善于倾听。适合想进行深度交流时。
4. **阳光鼓励型 (Cheerful & Encouraging)**：积极乐观、充满动力。适合需要激励和打气时。
