# Her

只为一个人长期使用的私人 AI 伙伴。当前已实现 **桌面聊天与 Her Tools V1 工具链路**，使用 Electron、React 和 TypeScript，模型在用户配置的云端服务运行，配置和聊天历史保存在本机。

## 当前可用

- 自定义 OpenAI Chat Completions、Claude / Anthropic Messages 兼容服务的地址、模型、密钥和额外请求头。
- 独立检测文字流式连接与完整工具调用能力；工具测试只检测协议，不执行业务操作。
- 流式文字、Markdown 展示、停止生成、失败重试、切换模型和多个对话。
- SQLite 保存历史；重启恢复对话，未完成的回答保留片段并标记中断。
- 菜单栏入口、关闭窗口后后台运行、可配置唤出快捷键和登录自启设置入口；源码运行暂不支持开启登录自启。

尚未接入语音、长期记忆、提醒、主动联系、虚拟世界、临时聊天或导出恢复。完整第一版的范围见[产品与技术设计](docs/superpowers/specs/2026-10-13-her-design.md)，Stage A 的实现与验收边界见[实施说明](docs/implementation/stage-a.md)。

## 安装与运行

需要 macOS、Node.js 24 或更新版本和 npm。在项目目录运行：

```bash
npm install
npm run dev
```

开发窗口打开后，在“设置 → 模型服务”添加一个服务即可聊天。构建后启动：

```bash
npm run build
npm start
```

`build` 生成 `out/main`、`out/preload`、`out/renderer`。`npm run package` 先构建，再用固定 `@electron/packager@20.3.0` 生成当前 Mac 架构的 `release/Her-darwin-arm64/Her.app`（arm64 示例），bundle ID 为 `com.her.desktop`。本机包不执行签名、公证、上传或发布。首次打包需要下载 Electron；网络受限时可使用下文的 `ELECTRON_MIRROR` 环境变量。

| 命令 | 用途 |
| --- | --- |
| `npm run package` | 构建并生成当前 Mac 架构的本地 .app |
| `npm run typecheck` | TypeScript 检查 |
| `npm test` | 核心与界面自动化测试 |
| `npm run check` | 类型检查、全部单测、构建 |
| `npm run test:e2e` | 构建并启动实际 Electron 做端到端测试 |

当前 Electron 版本在首次运行时下载二进制。若下载出现连接超时、连接重置等网络错误，先重试或更换可访问 GitHub 的网络；必要时使用 [Electron 官方安装文档](https://www.electronjs.org/zh/docs/latest/tutorial/installation)列出的第三方镜像，显式运行下载脚本：

```bash
ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/" node node_modules/electron/install.js
```

## 配置模型服务

1. 打开“设置 → 模型服务 → 添加服务”，填写服务名称、协议、Base URL 和服务支持的 Model ID。
2. 按服务要求填写 API Key，或在“额外请求头”中填写字符串键值的 JSON 对象，保存服务。
3. 分别运行“测试文字”和“测试工具”，然后点击“设为当前”或从聊天窗口右上角选择服务。

**Base URL 应包含服务要求的 API 路径前缀。** Her 去掉末尾斜杠后追加资源路径，不自动补 `/v1`，也不要填写完整的聊天接口地址：

| 协议 | Base URL 示例 | 实际请求路径 |
| --- | --- | --- |
| OpenAI 兼容 | `https://example.com/proxy/v1` | `/proxy/v1/chat/completions` |
| OpenAI Responses | `https://example.com/proxy/v1` | `/proxy/v1/responses` |
| Claude / Anthropic | `https://example.com/proxy/v1` | `/proxy/v1/messages` |

地址支持 HTTP / HTTPS，不接受 URL 用户名、密码、查询参数或片段；认证信息请放在 API Key 或额外请求头。OpenAI 默认发送 `Authorization: Bearer ...`，Anthropic 默认发送 `x-api-key` 和 `anthropic-version: 2023-06-01`。额外请求头可以覆盖同名默认头，例如第三方网关要求的版本或项目标识：

```json
{
  "X-Project": "my-project"
}
```

已保存的密钥和请求头不会回显。编辑时留空会保留原值；输入新值会替换，勾选“清除已保存的密钥”或“清除已保存的请求头”才明确清除。修改协议、地址、模型或凭据后，需要重新测试。

连接测试使用已保存配置，并会向所选服务发送小型测试请求；文字通过不表示工具能力通过。工具不支持时仍可文字聊天。请求失败会显示错误，Her 不会自动改发其他端点，也不会跟随携带凭据的 HTTP 重定向。

## 工具、文件与外部依赖

“设置 → MCP 工具”支持本地 stdio 和远程 Streamable HTTP。静态 Token/请求头由主进程加密；留空保留，显式清除才删除。连接测试证明发现工具，不代表目标应用或浏览器已经获得权限。仅支持 OAuth 登录的服务目前不能按静态凭据接入；prompts、sampling 与工具自己的嵌套 agent 不在首版范围。

- Mac 操作使用固定 Peekaboo 4.9.3。按预设指引分装依赖，由用户为实际执行宿主授予辅助功能/屏幕录制权限；换成安装包后应重新检查权限状态。
- Chrome 使用 Playwright MCP 0.0.83 和官方扩展，用户批准连接及标签范围后复用现有登录态。扩展授权和 Her 的发送/删除/覆盖确认是两个独立步骤。当前机器的扩展安装由用户暂缓，真实 Chrome 验收尚待完成。
- open-webSearch 2.2.0 为默认关闭的可选预设；启用后使用请求式公开检索，不复用 Chrome 登录态。
- 文档读取使用 MarkItDown 0.1.8 / MCP 0.0.1a7，支持 PDF、DOCX、PPTX、XLSX 等文字/表格提取，不保证复杂版式、物理页码或 Excel 公式重算。扫描页和图表由本地 PDF.js 按页渲染后交给当前视觉模型；能力不足会提示切换，不会自动换模型或端点。

依赖单独安装，Her 管理自己启动的工具进程。安装版的固定 npm 清单位于 `Her.app/Contents/Resources/mcp-web-dependencies/`，文档安装脚本与 74 包哈希锁位于 `Her.app/Contents/Resources/dependencies/markitdown/`；每个目录含安装说明。无需源码仓库，不捆绑外部 Node/Python、浏览器或研究虚拟环境。源码版对应 `resources/` 下相同目录。详细版本、安装命令与限制见[兼容记录](docs/implementation/her-tools-v1-compatibility.md)。依赖检查保存真实可执行路径，GUI 启动无需继承终端 PATH。

缺少工具或版本不符时，在“设置 → MCP 工具 → 从预设添加”选择工具并检查依赖，按结果中的官方下载按钮和安装步骤操作。网页工具和文档解析器提供“复制安装命令”，命令会使用当前 Her 的资源路径；复制后在终端运行，完成后点击“重新检查依赖”。下载或复制不会直接显示已安装。已保存的预设有“检查服务依赖”，连接失败时也会补充这些指引；“设置 → 资料授权 → 检查解析器依赖”提供同样的 MarkItDown 安装入口。macOS 权限和 Chrome 扩展显示单独授权步骤；扩展是否已批准连接，以实际连接测试为准。

添加资料即授权当前对话读取；目录可授权本次对话或长期使用。长期授权可在设置撤销，临时资料可在当前对话撤销；读取权限不包含修改原文件。读取、缓存、图片与来源打开均重新检查授权，撤销不撤回已经发送给模型的历史内容。新文档最多 50 MiB，文本分段最多 30,000 字符；PDF 每次最多 3 页、长边 2,000 像素，以物理页序定位。

全局同时执行一个任务，工具串行运行。发送、删除、覆盖和不明确操作先确认；停止立即阻止后续步骤，已经发生的动作不会自动回滚。默认全局停止键为 `Command+Shift+Escape`，可在桌面偏好更换；冲突会提示，聊天停止按钮一直可用。连续运行最多 40 次工具调用或 10 分钟活动时间，等待确认不计时。重启保留记录但不自动续做；继续任务会保留轨迹，未知结果需先观察或人工处理，不能直接重复派发。

真正退出会取消任务、最多等待 5 秒清理连接并终止 Her 自己启动的子进程，不关闭用户 Chrome。卸载 `.app` 不自动删除数据：先退出 Her，再按设置显示的目录备份/删除应用自管数据库、附件和缓存。分别安装的依赖在 `~/.local/share/her/dependencies/`；不再使用时可自行删除对应版本目录，MarkItDown 所依赖的 uv Python 仍被其他环境使用时应保留。永久删除会话会清理其专属资料，长期授权和其他会话仍引用的资料保留；不会删除用户源文件。

实际验收与模拟服务证据分别列在[Tools V1 验收记录](docs/implementation/her-tools-v1-acceptance.md)。

## 历史与桌面行为

数据使用 Electron 的应用专用 `userData` 目录，macOS 通常为 `~/Library/Application Support/Her`；实际位置可在“设置 → 桌面偏好”查看。数据库为 `her.sqlite`，普通历史与配置没有整库加密；API 密钥及额外请求头由 Electron `safeStorage` 加密后保存，macOS 使用系统钥匙串支持的保护方式，保护不可用时不会改存明文。

重启会恢复历史。聊天请求使用当前对话近期至多 50 条、约 64000 个字符的上下文；完整历史仍留在本机，这不等同于长期记忆。取消或失败的回答会保留已生成片段，重试替换该回答，不重复添加原用户消息。

关闭窗口会隐藏窗口并保持后台运行。通过菜单栏“显示 Her”、Dock 或快捷键可以再次唤出；默认快捷键为 Mac 的 `Command+Shift+H`，可以在桌面偏好中更换，冲突时会提示。应用菜单或菜单栏中的“退出 Her”才结束应用，未完成的回答会标记中断。源码运行时系统应用名称可能显示为 Electron。

登录自启默认关闭。当前源码运行尝试开启时会提示需要安装版；[Electron 文档](https://www.electronjs.org/docs/latest/api/app#appsetloginitemsettingssettings-macos-windows)说明 macOS 自启依赖打包、签名和公证，后续仍需系统实测，不能将设置入口视为已验证的自启能力。

## 验证边界

已在本机运行类型检查、单测、构建和实际 Electron 端到端测试。端到端测试连接独立的本地 HTTP 模拟服务，并为每次测试创建临时数据目录；它验证桌面应用、协议与本地持久化链路，不使用个人聊天资料或用户真实第三方账户。

**用户真实第三方端点、模型和密钥尚未验证。** 使用前请在应用中分别测试所选服务。验收记录和仍需人工核验的系统行为见[Stage A 实施说明](docs/implementation/stage-a.md)。

## 待实现的核心功能

Her 的完整愿景包含以下尚未实现的功能模块，详见[完整产品与技术设计](docs/superpowers/specs/2026-10-13-her-design.md)：

### 语音交互
- **本地语音识别**：集成 Apple SpeechAnalyzer/SpeechTranscriber 或 whisper.cpp 进行本地识别
- **语音合成**：接入 TTS 服务，支持流式语音输出
- **通话管理**：开启/结束通话、静音、打断播报、语音浮窗状态显示
- **双向交互**：文字和语音可在同一会话中自然切换

### 长期记忆系统
- **三类信息管理**：当前上下文、长期记忆、任务与世界事实
- **记忆提取与检索**：结构化存储用户偏好、重要经历、稳定背景
- **中文全文检索**：基于 SQLite FTS5，可选向量辅助检索
- **纠正与遗忘**：更新现状、"别记"模式、按范围清理记忆及依赖关系
- **关系发展**：保留关系摘要，基于有意义交流和共同活动自然发展

### 资料读取与工作协作
- **授权文件访问（已实现）**：读取用户明确授权的文本、Markdown、代码、项目目录与文档
- **工作话题隔离**：项目材料和工作记忆按项目分开，个人偏好跨话题共享
- **笔记与草稿**：保存到 Her 的笔记区，可阅读、修改、导出
- **资料引用（已实现）**：显示文件及实际提取位置，提供受控来源打开

### 提醒与主动联系
- **一次性提醒**：创建、修改、取消提醒，关联当前话题
- **定时触发**：使用 macOS 通知在指定时间提醒
- **主动交流**：在允许时段（10:00-22:00）每天最多两次自发联系
- **智能判断**：基于具体依据（如用户提过今天有重要事项）才主动联系
- **恢复机制**：Mac 休眠或关机后恢复时汇总错过的事项

### 虚拟世界
- **三个地点**：书房、窗边、附近公园
- **共同活动**：窗边聊天、书房共同工作、虚拟公园散步
- **2D 表现**：角色立绘、姿态切换、轻量动画
- **世界状态管理**：地点移动、活动开始/结束，通过工具调用更新
- **可收起面板**：显示当前地点、活动和近期共同活动历史

### 临时聊天与数据保护
- **临时模式**：不持久保存对话和长期记忆
- **选择性保存**：用户明确要求的提醒和产物仍可保存
- **备份与恢复**：手动导出/恢复数据（不含 API 密钥）
- **数据清理**：遗忘功能清理本地数据及衍生记忆

### 工作话题管理
- **多项目支持**：为不同工作项目创建独立话题
- **上下文隔离**：项目文件和工作记忆默认只在当前项目范围内检索
- **跨项目引用**：用户明确表达时可引用其他项目资料

### 桌面体验增强
- **全局快捷键**：当前已支持唤出快捷键，后续扩展更多操作
- **登录自启**：完善打包、签名和公证后提供可靠的开机自启
- **多窗口支持**：主聊天窗口、语音浮窗、世界面板独立管理

### 移动端扩展
- **iOS/iPadOS 应用**：同步对话历史、记忆和提醒
- **跨设备同步**：Mac 和移动设备间的数据同步机制
- **移动端适配**：针对触摸交互优化的 UI

## 开发路线

当前已完成 Stage A，并提前接入 Tools V1；真实服务与系统验收边界见上述记录，后续将按以下优先级推进：

1. **Stage B**：长期记忆与关系发展
2. **Stage C**：虚拟世界与共同活动
3. **Stage D**：资料读取与工作协作
4. **Stage E**：提醒与主动联系
5. **Stage F**：临时聊天与数据导出
6. **Stage G**：语音交互（本地识别 + TTS）
7. **Stage H**：移动端扩展

**优先级说明**：
- **长期记忆**是建立持续关系的基础，让 Her 能记住你的偏好和共同经历
- **虚拟世界**提供情感陪伴和共同活动的场景，增强相处体验
- **资料读取和提醒**扩展实用功能，让 Her 成为真正的工作伙伴
- **语音交互**作为交互方式的补充，在文字功能完善后再添加
- **移动端**在桌面端核心功能稳定后开始开发

具体实施计划和优先级可能根据实际验收结果调整。
