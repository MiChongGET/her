# Spec Delta

## Purpose

定义附件、工具与模型派生内容的来源依赖，以及撤权或来源失效后如何阻止相关材料继续进入模型请求、压缩和恢复路径。

## ADDED Requirements

### Requirement: 发送和读取前复核附件
附件在每次实际发送给模型和每次工具读取前 MUST 重新检查授权、文件存在性和版本。附件已失效时系统 MUST 阻止发送并提示用户。

#### Scenario: 附件文件已删除
- **WHEN** 排队消息引用的附件在发送前被删除
- **THEN** 该消息不发送，提示附件已失效

#### Scenario: 附件文件已被替换
- **WHEN** 附件引用的文件内容在授权后被替换
- **THEN** 系统按失效处理，不发送新内容冒充原附件

### Requirement: 派生内容记录来源依赖
由附件、工具结果或模型生成的派生文本 SHALL 记录其来源依赖。压缩摘要 MUST 继承其覆盖材料及前一份摘要的依赖。来源 MUST 由宿主记录，模型自报的来源或成功 MUST NOT 替代宿主验证。

#### Scenario: 摘要覆盖附件内容
- **WHEN** 会话被压缩，被压缩的历史引用了附件 X
- **THEN** 生成的摘要记录依赖 X

### Requirement: 撤权后相关材料不再进入请求
用户撤销授权、文件被替换或来源失效后，依赖该来源的材料、摘要和派生文本 MUST NOT 进入后续普通请求、压缩请求或恢复请求。相关在途请求 SHALL 被停止。原始记录 SHALL 仍可供用户查看。

#### Scenario: 撤销文件夹授权
- **WHEN** 会话中读取过授权文件夹 F 的文件，用户撤销 F 的授权后继续对话
- **THEN** 后续请求不包含来自 F 的内容或依赖它的摘要

#### Scenario: 撤权时请求在途
- **WHEN** 一个包含来自 F 的材料的模型请求正在进行时用户撤销 F
- **THEN** 该请求被停止

#### Scenario: 迟到结果不复活内容
- **WHEN** 撤权后一个读取 F 的工具结果才返回
- **THEN** 该结果不进入后续上下文

### Requirement: 依赖记录不保存敏感内容
来源依赖记录 MUST NOT 保存凭据，也 MUST NOT 保存不必要的原文副本。

#### Scenario: 检查依赖记录
- **WHEN** 检查资料目录中的来源依赖记录
- **THEN** 记录只包含来源标识和版本，不包含凭据或附件全文
