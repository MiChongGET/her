# Spec Delta

## MODIFIED Requirements

### Requirement: 消息状态显示在气泡内
流式生成中、失败、已停止、已中断的提示和重试按钮 SHALL 显示在对应消息的气泡内。失败、已停止和已中断的触发条件 SHALL 以该消息所属任务的状态为准。流式生成中和失败的原有文案 MUST NOT 改变。

#### Scenario: 流式中
- **WHEN** Her 的回答正在生成
- **THEN** "正在写…" 或 "Her 正在想…" 的提示显示在该回答的气泡内

#### Scenario: 失败后重试
- **WHEN** Her 的回答失败
- **THEN** 错误提示和"重试"按钮显示在该回答的气泡内，点击行为与之前一致

#### Scenario: 中断片段
- **WHEN** 回答因停止、退出或崩溃而未正式完成
- **THEN** 已显示的部分文字保留在气泡内，并在气泡内标明已中断

## ADDED Requirements

### Requirement: 任务过程状态在会话中可见
排队中的消息、等待审批、等待资源、压缩中和压缩失败 SHALL 在所属会话中以可见提示显示，与普通回答气泡区分。排队消息 SHALL 提供撤销入口。

#### Scenario: 排队消息
- **WHEN** 用户在任务运行中再发送一条消息
- **THEN** 该消息以排队状态显示，并带有撤销入口

#### Scenario: 等待资源
- **WHEN** 任务因另一会话占用桌面而等待
- **THEN** 会话中显示正在等待资源的提示

#### Scenario: 压缩中
- **WHEN** 会话正在压缩上下文
- **THEN** 会话中显示压缩进行中及停止入口
