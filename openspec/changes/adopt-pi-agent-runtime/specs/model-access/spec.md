# Spec Delta

## Purpose

定义用户如何在新运行底座下配置模型服务与凭据，包括 Pi 内置模型目录、自定义兼容服务、认证方式，以及凭据加密保存、隔离与按任务生效的规则。

## ADDED Requirements

### Requirement: 使用 Pi 模型目录中的内置模型
系统 SHALL 允许用户从 Pi 模型目录选择模型，并使用目录中的协议、上下文窗口、输出上限和能力信息作为该模型的容量与能力。

#### Scenario: 选择目录模型
- **WHEN** 用户新建服务并选择一个目录中的模型
- **THEN** 设置界面显示该模型的上下文窗口与是否支持图片、工具

### Requirement: 配置自定义兼容服务
系统 SHALL 允许用户配置自定义兼容服务的 base URL、协议、模型 ID、上下文容量和输出上限。缺少上下文容量时系统 MUST 要求用户填写，而非使用未知默认值。

#### Scenario: 保存自定义服务
- **WHEN** 用户填写 base URL、协议、模型 ID 和上下文容量并保存
- **THEN** 该服务出现在模型选择中，并以填写的容量参与压缩判断

#### Scenario: 缺少上下文容量
- **WHEN** 用户保存自定义服务但未填写上下文容量
- **THEN** 系统拒绝保存并提示填写

### Requirement: 区分三种认证方式
每个服务 MUST 明确选择一种认证方式：API Key、自定义请求头、或显式无密钥。无密钥和仅请求头模式下，发出的请求 MUST NOT 携带任何 API Key 或由系统生成的认证值；运行时内部使用的占位值 MUST NOT 落盘、出现在请求、日志或界面中。系统 MUST NOT 提供 OAuth 登录。

#### Scenario: 本地无密钥服务
- **WHEN** 用户为本地模型选择无密钥模式并发送消息
- **THEN** 请求不携带任何认证信息且能正常完成

#### Scenario: 内部占位值不外泄
- **WHEN** 无密钥服务完成一次请求后检查请求头、资料目录和日志
- **THEN** 都找不到运行时内部占位值

#### Scenario: 仅自定义请求头的网关
- **WHEN** 用户配置的网关只需要自定义认证头
- **THEN** 请求携带该请求头，不要求填写 API Key

### Requirement: 凭据按服务独立隔离
每个 Her 服务配置的凭据 MUST 独立存放和使用。同一供应商的不同网关 MUST NOT 共用凭据槽位，会话 MUST NOT 通过进程环境变量获得或切换密钥。

#### Scenario: 同供应商两个网关
- **WHEN** 用户配置两个同协议、不同 base URL 和不同 Key 的服务，并在两个会话中同时使用
- **THEN** 每个会话的请求只携带其所选服务的 Key

### Requirement: 凭据加密保存且不外泄
持久凭据 MUST 由系统加密能力加密后保存，MUST NOT 以明文写入资料目录、日志或返回渲染进程。系统加密能力不可用时，保存凭据 MUST 明确失败。

#### Scenario: 资料目录不含明文
- **WHEN** 用户保存 API Key 后检查资料目录中的全部文件
- **THEN** 找不到该 Key 的明文

#### Scenario: 设置界面读取服务
- **WHEN** 渲染进程获取服务列表
- **THEN** 结果只表明凭据是否已配置，不包含凭据值

#### Scenario: 加密不可用
- **WHEN** 系统加密能力不可用时用户保存 API Key
- **THEN** 保存失败并提示原因，不改为明文保存

### Requirement: 任务冻结配置且撤权立即生效
每个任务 SHALL 使用开始时的模型、服务和工具配置版本；普通修改只影响之后的任务。用户删除凭据、禁用服务或撤销工具授权 MUST 立即作用于正在运行的相关任务。

#### Scenario: 运行中修改服务名称
- **WHEN** 任务运行中用户修改该服务的显示名或输出上限
- **THEN** 当前任务按原配置完成，下一个任务使用新配置

#### Scenario: 运行中禁用服务
- **WHEN** 任务运行中用户禁用其使用的服务
- **THEN** 该任务不再发起新的模型请求并停止，显示服务已禁用

### Requirement: 用量缺失时不记为零
系统 SHALL 在服务返回用量时记录输入、输出 token；服务未返回用量时 MUST 标记为未知或估算，MUST NOT 记为 0。

#### Scenario: 服务不返回用量
- **WHEN** 一次模型请求完成但响应中没有用量信息
- **THEN** 该请求的用量显示为未知或估算
