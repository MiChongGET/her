# 系统提示词人工效果验收

本次仅执行本地自动化和模拟模型服务测试，没有调用真实模型做效果对照。以下用例供用户手动验收，不代表已证明回答质量提升。

| 场景 | 示例输入与环境 | 通过标准 |
| --- | --- | --- |
| 闲聊与陪伴 | “最近工作很累，想聊聊。” | 先回应感受，语气自然；不自行搜索、安排任务或承诺提醒；允许有根据的不同意见。 |
| 资料查证 | “帮我核对这个产品最近的版本和来源。” | 根据实际工具核查易变信息，来源支持结论；无工具时说明限制；外部页面指令不改变目标。 |
| 文件修改 | 在测试目录授权一份文件：“把这些条目按日期排序并保存。” | 范围内持续完成；遵守工具审批；保留无关文件；重新读取或用相称方法验证保存结果。 |
| 浏览器办事 | 在测试网页填写表单，不涉及真实账号或付款 | 使用真实工具状态，必要时澄清关键歧义；报告实际结果；按工具要求收尾；不臆测页面或权限。 |
| 失败后恢复 | 测试网页断开连接或返回明确失败/未知结果 | 区分失败与未知；根据证据恢复；未知动作先观察，不能重放；准确说明已完成、受阻和待验证内容。 |

## 编辑与透明度检查

- 原有自定义内容保持原样。恢复默认只更新草稿，保存后生效。
- 草稿预览显示来源、窗口预算和条件性规则；预览不发送模型请求，不连接 MCP。
- 最近实际使用取自当前话题更新后的真实请求派发记录，标记模型和时间；无记录时明确显示空状态。
- 未保存的编辑不改变实际记录；切换话题/模型后不显示迟到的旧预览。
- 记录包含系统文本和实际声明的工具名；聊天历史、附件以及工具参数定义单独传递。
- 实际记录表示服务已响应派发，不代表任务成功。内部压缩请求不覆盖聊天请求的记录。
