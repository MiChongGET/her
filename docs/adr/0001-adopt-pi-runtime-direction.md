# 以 Pi 作为 Her 的 Agent 运行底座

Her 决定以 Pi 作为后续 Agent 运行底座，以应对持续增长的会话内容，并复用上游对模型接入、Agent 执行和上下文管理的改进。相较继续独立维护这些机制，该选择接受一次适配迁移及后续 Pi 版本升级验证的成本；不以仅添加一个摘要功能作为迁移终点。

2026-10-19 用户确认：以 `pi-coding-agent` SDK 的完整会话运行能力为目标，由 Pi 接管模型调用、Agent 循环、会话上下文和自动压缩。首期聚焦底座与上下文压缩，长期记忆和 Graphiti 后续另行设计；旧聊天不迁移，不以旧实现兼容为验收目标。

本 ADR 确认架构方向和范围。Q1–Q16 产品决策已确认，完整方案见 [适配设计](../superpowers/specs/2026-10-19-her-pi-adapter-design.md)，尚待用户最终确认，不代表产品代码已经实施。
