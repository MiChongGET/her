# 明确的委托修正优先处理

2026-10-22 用户确认：在工作话题中，“先别发了”“把预算改成五百”等针对当前委托的明确修正应优先处理。停止发送的指令阻止后续发送；修改要求先暂停相关后续动作，核对新范围后继续，有歧义才追问。已经发生的动作按真实结果告知。

该决定有限调整 Pi 适配设计 Q10 的全部新消息排队规则。与等待当前任务完成后才处理相比，它使用户能及时改变正在办理的事情；代价是必须区分普通补充、无关聊天与委托修正，并保证控制作用于对应委托。

同日确认：在日常主聊天中没有唯一指代时，先拦住可能涉及的动作，再询问对象。例如两件委托各准备发送一条消息，“先别发”会先暂停两项候选发送；比较酒店等明确无关的工作继续。指代清楚时直接处理，不额外询问。该规则不将模糊指令解释为全局停止；完整决定见[交互设计](../superpowers/specs/2026-10-22-private-companion-interaction-design.md)。
