# 以有明确边界的委托组织授权

2026-10-22 用户确认：Her 以用户托付的一件事及其边界组织授权，允许范围内的动作连续执行。相较逐次询问每个工具步骤，该方案减少办事中的打断；相较长期放行某项工具服务的全部操作，该方案让用户能预测授权覆盖的事情与范围。以比较酒店为例，委托可覆盖浏览、筛选和整理，预订、付款或提交个人资料另行确认。

伙伴自然解释目的，系统卡片准确展示批准内容。解释与实际授予的范围必须一致，伙伴关系不扩大权限。

同日确认：对象唯一、最终内容完整且目标已经核对的普通消息发送，可以由用户的明确指令直接构成批准，省去重复点击。由 Her 拟定或仍有歧义的内容先预览再批准；预订、付款、提交个人资料仍需单独确认。本决定仅调整已讨论的消息发送场景，不将删除、覆盖等动作一并改为免确认。

委托以事情完成或用户明确取消为结束，可以保留到次日。切换话题不取消委托，暂缓后保留进展；应用重启后等待用户要求继续。继续时重新核对原范围与目标，关键内容变化再询问；未知动作先查明结果。保留委托不等于跨运行复用旧工具调用的批准，动作仍接受当次校验。完整决定见[交互设计](../superpowers/specs/2026-10-22-private-companion-interaction-design.md)。

拒绝某个步骤不自动取消整件委托，其余已获准的工作继续。Her 不得更换工具或说法重复尝试同一个被拒绝的动作；缺少该步骤确实无法继续时，说明原因并等待用户调整。暂缓与取消整件委托有各自明确入口。

取消“所有对话允许此工具的所有操作”的全局永久放行入口。工具连接配置可以长期保存，行动统一受具体委托的边界约束，既有全局放行配置不能继续作为绕过授权的依据。当前会话级浏览器放行同样不能覆盖委托边界，或绕过预订、付款等另行确认的要求。
