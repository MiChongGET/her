# 支持多个任务并行并隔离任务状态

2026-10-19 用户明确要求 Her 能同时运行多个任务且相互不影响，否决首期全局仅允许一个活跃任务的建议。新运行底座必须隔离任务的上下文、事件归属、审批、取消、压缩和失败；不能因停止或修改一个任务而停止其他任务，不能保留旧实现的全局单活跃请求作为产品限制。

相较全局串行执行，该决定接受并发生命周期和状态隔离的适配成本。用户随后确认：不同会话并行，同一会话同时运行一个任务；争用同一桌面或写入同一目标时，只对冲突的工具步骤排队，不串行整个任务。独立模型请求和其他不冲突的工作继续运行。

停止、压缩、切换模型或普通任务错误仅影响对应任务。进程崩溃、应用退出、网络中断及共享模型服务的限流仍是共同条件，不承诺运行状态隔离能消除这些外部影响。
