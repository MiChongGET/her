# 记忆传输许可随接收模型服务确认

本地保存的记忆仍可能为整理或回答而发送给模型服务，不能把本地存储当作从不外发的承诺。用户于 2026-10-23 确认 Q21：首次开启说明实际存储与处理路径，只发送当前必要且获准的片段；首次使用新的接收模型服务时明确确认该传输范围，之后不逐条询问，同一服务切换模型不因此重复确认。此许可不能覆盖来源、敏感信息、记忆停用或共享撤回限制，不默认整库上传、暗中增加第三方记忆服务，也不承诺撤回服务方已收到的内容；成本是维护清楚的服务许可边界，而非将一次开启解释为任意外发许可。

Q25 于 2026-10-23 确认：许可覆盖个人记忆、关系理解、工作共享摘要及旧回答或压缩材料中的记忆衍生，普通旧聊天也不随切换自动发送，继承旧话题须说明所选历史的传输范围并保留原有限制。拒绝后可从用户明确交给新服务的当前输入或选定普通材料开始新交流，不夹带受限记忆、不自动回退原服务；材料边界无法可靠划清时先不发送相关材料并说明原因，代价是跨服务延续旧交流需要明确范围。

适配 A2 又明确：首版不增加独立整理模型设置，整理复用来源所属交流的模型配置，同时满足接收方对本次材料的实际许可；一次整理绑定配置与许可，不因前台切换而悄悄改发，不以“当前模型”代替传输许可。首版范围及取舍见 [ADR-0015](0015-scope-first-companion-memory-adaptation.md)。
