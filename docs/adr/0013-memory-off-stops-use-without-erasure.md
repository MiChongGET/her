# 停用个人记忆停止整理和使用，不代替遗忘

记忆开关若只停止新增，用户关闭后仍可能被旧记忆影响；若把关闭等同删除，又会意外抹去用户希望保留的过去。用户于 2026-10-23 确认 Q14–Q15：关闭个人记忆同时停止新增整理与后续调用，内容保留可查，真正清理走遗忘；重开只恢复仍有效、仍获准的旧内容，不补记关闭期间，也不复活已撤回、排除或遗忘的来源。首次开启默认从当时开始，补记过去须用户选定来源和范围，不能因开启功能自动追认全部旧聊天；工作进展共享继续独立控制。

Q23 又明确：关闭期间的一次“记住这个”不自动打开总开关或恢复其他旧记忆，先如实说明尚未长期保存；用户明确开启后再处理指定内容，不一并补记关闭期间其他聊天。

Q24 于 2026-10-23 确认：关闭时建立新的交流起点，旧聊天可查但不自动带入后续回答，用户重新提供的内容可支撑本段连续交流，跨天或重启恢复不自动带回关闭期间个人事实，主动选定旧片段仅允许当次理解；代价是继续旧话题可能需要补充背景，独立工作仍按自身范围继续。Q26 同时确认一项最小例外：关闭期间明确得知变化且能确定关联时，仅使旧敏感条目失效，以防重开恢复错误现状，不保存新敏感事实或经过、不开展常规整理、不调用旧内容参与回答、不回扫关闭期间聊天；关联不明不擅自修改，必要时仅核对相关旧认识。
