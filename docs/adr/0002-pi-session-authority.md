# 以 Pi 会话条目作为运行历史的权威记录

2026-10-19 用户确认：由 Pi 会话条目管理运行历史、分支和压缩检查点；SQLite 管理会话索引、设置、权限和任务审计，展示所需消息作为可重建投影。相较继续用旧消息表重建并驱动 Pi 上下文，该方案优先跟随上游会话机制，接受跨存储恢复与删除联动的设计成本。

旧聊天不迁移，旧数据库和旧协议行为不要求兼容。用户进一步确认新版本使用独立数据目录，旧服务配置、凭据、MCP 配置和任务记录也不导入，保留原目录且不自动删除。目录、投影更新和多存储恢复的工程方案见 [适配设计](../superpowers/specs/2026-10-19-her-pi-adapter-design.md)，随完整方案交付最终确认。
