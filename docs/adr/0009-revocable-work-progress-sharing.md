# 工作进展共享可撤回后续使用

2026-10-22 用户确认：日常主聊天可以使用工作话题的简短进展及用户明确表达的感受，各工作话题可以关闭“带回日常”。共享摘要仍属于项目信息，原始文档、代码和详细讨论留在工作话题。

关闭共享后，该话题已经带回的摘要及其派生记忆也退出后续日常回答的使用范围。与仅停止新增摘要相比，这要求追踪共享内容的来源与衍生关系，但使收回共享真正影响后续回答。既有聊天记录保留供用户查看，清除记录通过独立的遗忘操作完成；原工作话题仍可使用自己的资料。

未共享的工作话题等待用户处理时，日常界面和窗口隐藏时的通知可以显示通用待处理状态，但不显示话题标题、目标或正文。用户进入所属工作话题后才查看详情并处理；待处理提示不构成内容共享。

2026-10-23 的记忆产品访谈进一步确认：用户明确要求跨话题长期记住的具体个人内容，可建立单独且清楚展示的个人记忆许可，见 [ADR-0012](0012-separate-explicit-personal-memory-from-work-sharing.md)。该例外不适用于自动提取的工作摘要及其派生记忆，也不放开其他工作内容；本 ADR 对普通共享派生内容的撤回规则继续有效。
