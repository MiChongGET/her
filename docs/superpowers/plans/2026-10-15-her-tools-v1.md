# Her Tools V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付已确认的 Mac 操作、Chrome 搜索与交互、本地资料读取、扫描 PDF 和可配置 MCP 能力。

**Architecture:** 保留 ChatService、现有模型适配与工具注册表，在主进程增加任务记录、动作确认、MCP 连接和受控文件服务。React 通过窄 IPC 展示状态、配置和资料；预设工具共用同一执行入口。

**Tech Stack:** Electron 44、React 19、TypeScript、Node >=24、node:sqlite、MCP TypeScript SDK、Peekaboo、Playwright MCP、MarkItDown、PDF 本地渲染、Vitest、Playwright Electron。

**Spec:** [定稿设计](../specs/2026-10-15-her-tools-v1.md)，尤其第九节默认值。状态：2026-10-16 软件实施与本机包门禁已完成，部分真实验收待人工；2026-10-15 从 T01 开始。逐任务验收记录见下方实施进度。

## Global Constraints

- 全局 1 个任务；任务内工具串行。
- 桌面、浏览器和文档任务沿用当前聊天模型；能力不足时提示用户切换，不自动更换端点。
- 发送、删除、覆盖前确认；结果未知先观察，停止不意味着回滚。
- 文件读取授权不自动增加对原文件的写入授权。
- 主进程加密保存；空字段保留，显式清除；配置 revision 变化后旧测试结果和旧确认失效。
- 每个实现任务先写有意义的失败测试，观察 RED，再实现和验证 GREEN；文档/静态样式不添加镜像测试。
- 当前工作目录不是 Git 仓库，不自行初始化、提交或推送；每项以目标测试和变更清单作为交付记录。若执行时环境变化，先重新检查工作区。
- 保留现有功能和无关工作；不改动 experiments 下的独立实验或其他 OpenSpec 变更。

## Review Focus

- 动作已派发但超时、退出或断线：不能重复发送/输入；T03、T07、T13 验证。
- 确认、连接测试、解析结果迟到：不能复活已停止任务或覆盖新配置；T03、T04、T10、T12 验证。
- v4 数据和旧图片/工具记录：迁移后可读，三种模型协议实际收到合法图片；T01、T02 验证。
- 授权目录符号链接、解析中撤销及跨会话缓存：不能返回新内容；T09–T12 验证。
- Terminal 成功而 GUI/安装包失败：路径、TCC 身份、PDF worker、退出清理要在 .app 验收；T06、T07、T11、T13 验证。

## 共享契约与文件职责

所有新增名字是本计划约定，尚不存在。公共 DTO 定义在 `src/shared/types.ts`；主进程私有执行接口在 `src/core/tools/types.ts`。不创建 AGENTS 中提到但当前不存在的 `src/preload/index.d.ts`。

| 契约 | 字段/签名 | 定义任务 |
| --- | --- | --- |
| ToolExecutionContext | `{runId, conversationId, callId, signal: AbortSignal}` | T01 |
| ToolResult | `{content: ToolContent[], isError?, structuredContent?, meta?, truncated?}`；text 块含 text，image 块含 artifactId/mimeType，resource_link 块含 uri/name | T01 |
| ToolMessage | 保留 role/tool_call_id；content 为 string 或 ToolResult，旧值在格式化边界规范化，不把内部对象直接传上游 | T01 |
| ArtifactReference | `{id, conversationId, mimeType, byteLength, sourceFileId?}`；路径不暴露，原图不进入常规会话 DTO，显式受控预览可返回数据 | T01 |
| TaskRun | `{id, requestId, conversationId, assistantMessageId, status, providerId, model, toolCallsCount, activeMs, continuationOf?}`；status 为 running/awaiting_confirmation/paused/stopped/completed/failed | T01 |
| ToolCallRecord | 保留 id/name/arguments，result 可读取旧 string 或新 ToolResult，派发前可为空；新增 runId/status/startedAt/finishedAt；status 为 pending/awaiting_confirmation/running/succeeded/failed/cancelled/unknown；旧记录缺少状态时不推测副作用成功 | T01 |
| ToolExecutor / ToolRegistry.execute | `(args, context): Promise<ToolResult>` / `(name, args, context): Promise<ToolResult>`；调用点统一迁移 | T01 |
| ActionAssessment | `{effect: read/interact/send/delete/overwrite/unknown, target, summary, observationId?}`；由预设适配器/Host 判断，未知自定义工具默认 unknown | T03 |
| ApprovalRequest / Decision | 请求含 id/runId/callId/revision/target/summary；决定仅含 approvalId/revision/decision(approve/reject)；参数摘要和服务版本在 Host 绑定 | T03 |
| ContinueTaskInput | `{runId, requestId, profileId, model?}`；继续从 UI 明确传入当前模型选择，新任务保留 continuationOf 与旧执行轨迹 | T03 |
| TaskEvent | `{requestId, conversationId, run: TaskRun, approval?: ApprovalRequest}`；不携带凭据或原图 | T03 |
| McpServiceConfig | id/name/presetId?/enabled/transport(stdio/streamable-http)/revision；stdio 含 command/args/cwd?，HTTP 含 url；公共部分仅含 secretKeys 和 hasSecrets | T04 |
| SaveMcpServiceInput | 上述可编辑字段 + expectedRevision? + secretValues? + clearSecretKeys?；env/headers 的值均通过 secretValues 加密保存 | T04 |
| McpConnectionStatus | `{serviceId, revision, state: disconnected/connecting/ready/error, message?, toolCount}`；运行态不作为持久配置存储 | T05 |
| FileGrant / FileReference | grant 含 id/scope(conversation/persistent)/conversationId?/kind(file/directory)/displayName/revision；file 含 id/grantId/name/mimeType/size/version | T09 |
| DocumentReference / DocumentChunk | reference 含 id/fileId/version/status(ready/partial/empty)/parserVersion；chunk 含 documentId/text/source/range({offset,length})/truncated/nextCursor?；source 含 fileId/name/section?/sheet?/pageNumber? | T10 |

所有文件和缓存读取返回前、图片进入模型输入前再次检查所属会话及 sourceFileId 授权；没有 sourceFileId 的工具截图仍检查会话所有权。旧消息保留可见历史，不能把撤销描述成撤回已发往模型的内容。
