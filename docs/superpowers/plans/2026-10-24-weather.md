# Her 天气工具与顶栏 Implementation Plan

> **For agentic workers:** 使用 TDD 逐项实现并验证，不自动提交现有工作区。

**Goal:** 手动选择城市，在右上角显示天气，并让 Samantha 按需查询。

**Architecture:** 主进程 WeatherService 统一访问 Open-Meteo，城市与最近成功天气保存在现有设置。IPC 和内置模型工具复用服务；独立 WeatherWidget 负责顶栏交互。

**Tech Stack:** Electron、React、TypeScript、Vitest、Playwright；不新增 npm 依赖。

**Spec:** `docs/superpowers/specs/2026-10-24-weather-design.md`

## Global Constraints

- 仅手动城市，不使用 IP 或系统定位。
- 30 分钟刷新，失败保留旧结果并标记，超过两小时隐藏温度。
- 含今天共 7 天，以及今天、明天的逐小时天气；摄氏度。
- 保留现有未提交修改，城市查询不更改顶栏城市，后台不调用模型。

## Review Focus

- 同名城市：必须由候选明确选择。
- 断网与缓存过期：旧温度不能被冒充新天气。
- 城市切换竞态：旧结果不能覆盖新城市。
- 工具伪装：仅真实内置天气执行器可免逐次确认。
- 夜间和键盘：图标、浮层及焦点在两种外观下可用。
